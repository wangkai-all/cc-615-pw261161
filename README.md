# 分层抽样质检与总体缺陷率估计演示

一个完全使用 **Node.js 内置模块**（`node:http` / `node:fs` / `node:test` 等，零依赖）
的演示应用：底册按工段 × 班次 × 风险分层，抽样器按风险分层抽样，质检端判定
是否命中缺陷，分析端在保留抽中概率与样本排除依据的前提下估计全厂缺陷率及其
不确定范围。所有数据均为**可重复生成的虚构记录**。

## 启动

```bash
node server.js            # 默认 http://127.0.0.1:3000
PORT=8123 node server.js  # 读取 PORT 环境变量，始终绑定 127.0.0.1
```

## 测试

```bash
node --test               # 55 个用例，覆盖正常与异常结果
npm test                  # 等价
```

## 页面三个真实功能

| 按钮 | 后端接口 | 作用 |
| --- | --- | --- |
| 生成分层抽样结果 | `POST /api/sample` | 生成虚构底册，按等比/Neyman 优化分配做分层不放回抽样，质检端逐样本判定，写入每层抽中概率 πₕ = nₕ/Nₕ |
| 模拟空层和撤回复核 | `POST /api/incident` | 指定风险层整层置空（标识损坏无法判定），并撤回若干样本复核；排除样本仍保留抽中概率与排除依据 |
| 查看估计组成 | `POST /api/estimate` | 输出分层加权点估计、95% 不确定范围、每层组成、朴素池化值与高风险外推对照 |

业务结果区 `#resultArea` 带 `data-evidence-result` 属性，每次真实操作后更新
（如 `sampling:proportional:n=60`、`incident:empty=低风险:excluded=23`、
`estimate:renorm:point=10.79%`、`error:400`），可用于核对操作前后内容变化。

## 估计方法（src/estimation.js）

- 分层加权点估计：`p̂ = Σ Wₕ pₕ`，其中 `Wₕ = Nₕ/N`。
- 方差（不放回）：`V = Σ Wₕ² (1 − fₕ) pₕ(1−pₕ)/(nₕ−1)`，`fₕ = πₕ`；
  单层 `nₕ=1` 时该层方差项记 0，不产生 NaN。
- 三种空层处理：
  - `full`：要求每层可估，有空层直接报错（不静默忽略）；
  - `renorm`：仅在可估层上重归一化权重，点估计只覆盖部分总体，并显式报告覆盖缺口；
  - `conservative`：空层缺陷率按 `[0,1]` 并入总体区间，不确定范围随缺口变宽。
- 层区间使用 Wilson score interval，总体区间为 95% 正态近似并截断到 `[0,1]`。
- **禁止**用高风险样本比例直接推全厂：页面与接口同时给出该外推值（带警示）、
  朴素池化比例（忽略分层权重）和正确的分层估计，三者可直接对照偏差。

## 可重复性

固定种子（`registry-2026w47` / `sample-2026w47` / `incident-2026w47`），
基于 mulberry32 PRNG；相同参数反复执行得到完全相同的底册、样本、质检结果与
排除清单。

## 目录结构

```
server.js              HTTP 服务（内置模块，读取 PORT，绑定 127.0.0.1）
src/
  rng.js               确定性 PRNG 与洗牌
  population.js        虚构底册生成（工段/班次/风险分层）
  sampling.js          等比分配 / Neyman 优化分配 + 分层 SRSWOR
  qc.js                质检端判定
  simulation.js        空层与撤回复核情景
  estimation.js        分层估计、三种空层变体、区间与偏差对照
  app.js               编排与会话状态
public/                前端页面（index.html / app.js / styles.css）
test/                  node:test 用例（rng/底册/抽样/估计/情景/HTTP API）
```

## 异常路径（测试已覆盖）

样本量超过底册总量、未知分配方式/估计变体、空层时误用 `full`、无有效样本、
撤回数超过剩余样本、置空本就无样本的层、非法 JSON、未知路由、未抽样先估计等，
均返回明确错误且不会破坏已有会话状态。
